# MSB_COMBAT — прошивка ПЛИС платы коммутации режимов (МСБ)

Проект ПЛИС для платы **МСБ (DIAS.901.02.00.200 Е3)** — периферийной платы
баллистического компьютера. Вся управляющая логика (протоколы, алгоритмы
поведения) находится в процессоре STM32; ПЛИС выполняет функции регистровых
периферийных блоков, доступных через SPI-мост.

## Целевое оборудование

| Параметр | Значение |
| :--- | :--- |
| ПЛИС | **Xilinx Spartan-6 XC6SLX9-TQG144** (скорость −3) |
| Конфиг. FLASH | W25Q128 (в пользовательском режиме заблокирована) |
| Тактовый генератор | 60 МГц на P55 → DCM ×5/3 → 100 МГц внутренний |
| Связь с MCU | SPI1 STM32 (Mode 0), PB0 = polling-CS |
| Дискретные входы | 31 (оптопары HCPL-063L + буфер 8T245 на DR) |
| Дискретные выходы | 8 (активные уровнем 0) |
| Линия ВС | 2× RS-485/RS-422 (DD19/DD20), мультиплексируемые на USART2 STM32 |

> Историческая справка: в настройках проекта некоторое время ошибочно числился
> XC6SLX4TQG144. Реальный кристалл на плате — **XC6SLX9TQG144**; исправление
> внесено в `.adf`/`.ini`/комментарии (коммит `64c7a77`). Сборка идёт под LX9.

## Функции прошивки

* **31 дискретный вход**: 2-FF синхронизация → программная инверсия → фильтр
  дребезга 3 мс → подмена soft-значением → S/H-снимок 100 Гц или чтение в реальном времени;
* **8 дискретных выходов** с аппаратной инверсией и сторожевым сбросом (watchdog по записям STM32);
* **SPI-регистровый мост**: транзакция ровно 32 такта = командное слово (R/W + 10-бит адрес) + данные;
  3 устройства: `DEV1 debug`, `DEV2 FCS входы/выходы`, `DEV3 контроллер прерываний`;
* **мультиплексор RS-485** (DD19/DD20) с удержанием неактивного трансивера в покое;
* программируемый таймер выборки (100 Гц по умолчанию) и W1C-контроллер прерываний;
* диагностика: 3 тестовые точки с коммутатором 32:1 (любой внутренний сигнал на осциллограф),
  3 светодиода, ChipScope под макросом (по умолчанию выключен).

## Сборка

1. **ISE 14.7** (`msb_combat.adf`, Project Navigator): Synthesize (XST) → Implement
   (ngdbuild/map/par/bitgen). Итог: `implement/ver1/rev1/msb_main.bit`.
   Временное ограничение одно (такт 60 МГц); `spi_stm32_sck` на P70 —
   `CLOCK_DEDICATED_ROUTE=FALSE`, переносить пин SCK нельзя (джампер на плате).
2. **Симуляция**: Active-HDL 9.2, testbench в `tb/`.
3. **Программирование**: iMPACT через USB-кабель, либо загрузка конфигурации
   от STM32 (управление PROGRAM_B и внешним сбросом).

## Проверка связи со стороны STM32

1. Прочитать сигнатуры присутствия: `DEV1+0x01` = `0xDEAD`, `DEV2+0x02` = `0x55AA`.
2. Самодиагностика SPI: регистр `DEV1+0x00 FEED_BACK` — считанное значение
   должно совпадать с записанным.
3. После сброса ПЛИС работоспособна без конфигурации: фильтрация и опрос
   входов выполняются, значения по умолчанию `MISC = 0x00A0`
   (таймер 10 мс, канал DD19).
4. Полные карты регистров, входов/выходов и точек TP —
   в [ОПИСАНИЕ_ПРОШИВКИ_MSB_COMBAT.md](ОПИСАНИЕ_ПРОШИВКИ_MSB_COMBAT.md).
